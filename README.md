# Base Verified Quest

A beginner friendly onchain project built on Base.

## About

Base Verified Quest is a small project for learning how onchain user verification works with Base Verify.

## Goals

* Learn smart contract development
* Understand onchain verification
* Work with Base Sepolia
* Build a simple Web3 application
* Learn how to protect a quest from duplicate participation

More features will be added step by step.
